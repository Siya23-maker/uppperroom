# Logo goes here

Save the supplied **Upper Room logo** in this folder as:

```
assets/images/logo.png
```

It is used in the header, mobile menu, footer and as the Open Graph placeholder image.
Until the file exists, the site shows the typeset name "The Upper Room" instead —
the logo artwork is never redrawn.

If the file has a different name or format (e.g. `logo.svg`), either rename it or
update `logoPath` in `src/config.js`.

`favicon.svg` is a temporary "UR" monogram — replace it with a favicon made from the real logo.
